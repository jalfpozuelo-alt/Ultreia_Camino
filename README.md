# Ultreia Camino Web V1
Aplicación web móvil/PWA para iPhone con dos módulos: Control de Gastos y Seguimiento de Grupo.

## V1
- Hub inicial para entrar en los dos módulos.
- Control de Gastos basado en la versión V7.
- Seguimiento de Grupo con mapa OpenStreetMap y GPS real del teléfono.
- La sincronización de posiciones entre teléfonos todavía requiere conectar este front-end al mismo backend Supabase de la aplicación Flutter. La interfaz deja preparado el flujo y permite probar GPS/mapa inmediatamente.
- Preparada para GitHub Pages y pantalla de inicio del iPhone.
